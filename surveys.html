Data Collection Instruments

Survey & Test Instruments

The four instruments used to collect data during the field session. Print them, or display them on a screen. Everything on this page is paper-based — nothing is submitted anywhere and no student information is collected by this website.

See the analysis format

🔒 Privacy and safety — how these instruments are used

These forms are printed and filled in by hand or administered on paper. This website does not collect, store, transmit or upload any student response, and there is no submission button anywhere on this page. Students are minors, so the design deliberately avoids collecting names on the test papers: each student writes an anonymous code instead (see the note below), which is how a pre-test can be matched to its post-test without identifying anyone.

How to match a pre-test to its post-test without using names

Ask each student to write a private code made of three parts: the first two letters of their mother's name, the day of the month they were born, and the number of letters in their own name. For example: SU-14-6. The student writes the same code on both papers. The code is unique enough to match the pair, and meaningless to anyone else — so the comparison can be made without a single name appearing in the data set.

Instrument 3 · After the session

Post-Test

Identical to the pre-test. The questions are repeated word-for-word, in the same order, because any change to the wording would make the before-and-after comparison meaningless. Allow about 10 minutes.

Give each student the pre-test question paper again, and ask them to write the same anonymous code they used before. Do not let students see their earlier answers — the comparison must reflect what they know now, not what they wrote down an hour ago.
