Activity 05 of 05 · Variables

Guess the Output

Be the computer. A variable is a labelled box that holds a value — and that value can change while the program runs. Follow each line in order and predict exactly what will be displayed.

🎯

What you will learn

What a variable is, how its value changes as a program runs, and how to trace a program by hand.

🕹️

How to play

Read each program from the first line to the last, keep track of every value, then choose the output you expect.

⭐

Use paper

Write the variable name and cross out the old value each time it changes. Doing this by hand is how professional programmers check their own logic.

Why the box has a name

If you had to remember "the number that is currently 16" instead of calling it x, writing a program would be impossible. Giving a value a name lets you talk about it, change it, and compare it with other values — which is the whole foundation of programming.

Understanding it

Variables and tracing, step by step

Think of a variable as a labelled box on a shelf. set x = 5 means: find the box labelled x and put the number 5 inside it. Later, set x = x + 3 means: look inside the box, take what is there, add three, and put the result back in the same box.

That last line confuses almost everyone at first, because x appears on both sides. It helps to read it as: "work out the right-hand side first, then store the answer in the box on the left." The old value is not lost by accident — it is deliberately replaced.

Tracing is the name for working through a program by hand in this way, writing down each value as it changes. It is slow, unglamorous, and the single most reliable way to find out why a program is doing something unexpected.

Reading it as a trace table

Work through the first question as a programmer would. Write the value of x after each line:

LineInstructionValue of x
1set x = 55
2set x = x + 38
3set x = x * 216
4print xdisplays 16

Making a table like this for every program in the activity is a legitimate strategy — it is not cheating, it is exactly what the activity is teaching.

🔢

Numbers and text are handled differently

Adding two numbers gives their total: 4 + 6 = 10. But "adding" two pieces of text glues them together: "Good" + "Morning" gives "GoodMorning" — and no space appears unless you put one in yourself. Same symbol, two different jobs, decided by what is on either side.

🔁

Variables plus loops

A variable that changes inside a loop is the heart of most useful programs — counting how many students passed, adding up a total, or building a sentence one word at a time. When you can trace both together, you can trace almost any beginner program.

🎉 You have now met all five core concepts

Sequence, debugging, conditions, repetition and variables — that is the foundation the rest of programming is built on. Every language you will ever meet (Python, Java, JavaScript, C++) is a different way of writing exactly these five things.
