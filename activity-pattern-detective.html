Activity 04 of 05 · Loops

Pattern Detective

Computers are wonderful at doing the same thing over and over without getting bored. Find the rule hiding in each pattern, and you have just found the thing a loop repeats.

🎯

What you will learn

How to spot a repeating rule, and how that rule becomes a loop in a program — one instruction that runs many times.

🕹️

How to play

Look at the sequence, work out how one term leads to the next, and choose what belongs in the following position.

⭐

Ask two questions

"How much does it change each time?" and "is it adding, or multiplying?" Add and multiply give very different answers after a few steps.

Why a loop saves so much work

Imagine printing the numbers 1 to 1000. Writing a thousand instructions is not just boring — it is error-prone, and impossible to change if you decide you wanted 1 to 2000 instead. A loop does the same job in three lines, and changing one number updates the whole thing.

Understanding it

From a pattern to a loop

A pattern is a rule that produces a series. Once you can state the rule in words — "start at 2 and keep adding 2" — you have written a loop, just not in a programming language yet.

Loops matter because computers do not get tired. A task that would take a person a week of repetitive work takes a computer a fraction of a second, and the computer will not lose concentration on repetition number 9,000. Almost everything useful a computer does — searching, sorting, counting, drawing — is a loop somewhere underneath.

Reading it as real code

Three of the patterns from this activity written as loops. Notice that the rule you spotted is the loop:

# 2, 4, 6, 8, 10  — add 2 each time
for n = 2 to 20 step 2:
    print n

# 20, 17, 14, 11  — subtract 3 each time
for n = 20 down to 2 step -3:
    print n

# 3, 6, 12, 24  — double each time
set n = 3
repeat 4 times:
    print n
    set n = n * 2

Patterns are everywhere

🌻

In nature

The number of petals on many flowers, the spirals in a pine cone and the arrangement of seeds in a sunflower all follow the same sequence used in question 4 of this activity.

🎵

In music

A repeating drum rhythm is a loop. A chorus that comes back after each verse is a loop with an exit condition. Music software literally calls these sections "loops".

📐

In art

A tile design that repeats across a floor, or a border that runs around a page, is a pattern generated by repeating a single shape — exactly what the last question in this activity asks about.

Careful: the most common mistake

With a pattern like 3, 6, 12, 24 it is tempting to add 3 and answer 27. But 3 → 6 is also "add 3" and 6 → 12 is "add 6", so adding does not hold. The rule is multiplying by 2, giving 48. Always test your guessed rule on at least two steps before committing to it.
